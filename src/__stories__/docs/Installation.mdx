# Installation

Meda is published to npm as `@medalsocial/meda`. It supports React 19+ and ships ESM-only.

## Install

```bash
pnpm add @medalsocial/meda lucide-react
```

`lucide-react`, `react`, and `react-dom` are peer dependencies. The optional `themeAdapter="next-themes"` shell bridge is built into Meda for compatibility and does not require installing `next-themes`.

## Import the runtime CSS

In your app root entry, import the packaged stylesheet:

```ts
import '@medalsocial/meda/styles';
```

This pulls in:

1. Canonical design tokens from `tokens.css`
2. Tailwind v4 theme mappings from `theme.css`
3. Meda's base component styles

## Use a component

```tsx
import { AppShell, MedaShellProvider } from '@medalsocial/meda/shell';
import { Inbox, Settings } from 'lucide-react';

const workspace = { id: 'workspace', name: 'Workspace' };
const apps = [{ id: 'inbox', label: 'Inbox', icon: Inbox }];
const iconRail = {
  mainItems: [{ id: 'inbox', label: 'Inbox', icon: Inbox, to: '/inbox' }],
  utilityItems: [{ id: 'settings', label: 'Settings', icon: Settings, to: '/settings' }],
};

export function App() {
  return (
    <MedaShellProvider workspace={workspace} apps={apps}>
      <AppShell variant="workspace" iconRail={iconRail}>
        {/* app content */}
      </AppShell>
    </MedaShellProvider>
  );
}
```

Subpath imports such as `@medalsocial/meda/shell`, `/shell/primitives`, `/auth`, `/auth/better-auth`, `/recipes/next`, `/theme`, `/chat`, `/voice`, `/timeline`, and `/panel` keep the bundle focused.
